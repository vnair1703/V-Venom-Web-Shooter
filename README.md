# V Venom Web Shooter

A collaborative engineering design project exploring a wearable, wrist-mounted launcher for a web-like fluid stream. I contributed to the 3D-printed PLA housing and integration of the pressure, housing, and nozzle-trigger subsystems, then applied Bernoulli analysis and the Haaland and Churchill friction-factor correlations to evaluate nozzle flow and losses for a 4 m range target.

## Project overview

The prototype combined a wrist-mounted mechanical launcher, a pressurized fluid system, and a trigger/nozzle assembly. The work covered CAD, additive manufacturing, fluid-flow analysis, and prototype testing. This repository collects the project proposal, design reports, and calculation workbooks. It documents the project; it is not an operating or safety guide.

## Repository contents

- `reports/Project Proposal.docx` — project concept and objectives.
- `reports/Midterm Design Report.docx` — design development and prototype documentation.
- `reports/Final Design Report.docx` — final design, analysis, and reported test results.
- `calculators/Haaland Equation Calculator.xlsx` — friction-factor calculation workbook.
- `calculators/Churchill Equation Calculator.xlsx` — friction-factor calculation workbook in SI and EE units.

The prototype was developed collaboratively. The original reports retain their full authorship and academic context; this overview highlights my contributions without claiming sole authorship.
