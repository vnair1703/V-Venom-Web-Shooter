# V Venom Web Shooter

Course design project documenting the concept, analysis, fabrication, and testing of a wrist-mounted web-shooter prototype developed for EGR 313 at Arizona State University in Fall 2025.

## Project overview

The project combined a wrist-mounted mechanical launcher, a pressurized fluid system, and a trigger/nozzle assembly. The team used fluid mechanics, CAD, 3D printing, and prototype testing to develop the design. The included reports and spreadsheets are preserved as project records; they are not operating or safety instructions.

## Repository contents

- `reports/Project Proposal.docx` — original project concept and objectives.
- `reports/Midterm Design Report.docx` — design progress and prototype documentation.
- `reports/Final Design Report.docx` — final design, analysis, and reported test results.
- `calculators/Haaland Equation Calculator.xlsx` — friction-factor calculation workbook.
- `calculators/Churchill Equation Calculator.xlsx` — friction-factor calculation workbook in SI and EE units.
